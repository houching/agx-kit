## Architectural Principles

1. **Leaf-First Dependency Resolution**: Changes are validated starting from leaf modules before touching orchestration layers.
2. **Oracle Parity & Zero Tampering**: Existing tests and baselines are immutable truth. Fix implementations, never weaken assertions.
3. **High-Density Technical Aesthetics**: Built on the Vantage design language (`#0d0f12` slate canvas, 1px structural hairlines, tabular monospace data).
4. **Local Sovereignty**: All agent instructions, memory, rules, and scripts live inside `.agents/` in your repository.
