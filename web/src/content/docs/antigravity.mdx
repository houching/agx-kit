## Tool safety hook

`hooks.json` registers a native `PreToolUse` gate for `run_command`. It is deliberately narrow — it blocks high-confidence destructive patterns only:

- Unix root-filesystem deletion (`rm -rf /` and equivalents)
- Filesystem formatting and raw-disk overwrite (`mkfs`, writing to `/dev/sdX`)
- Windows drive formatting and forced root deletion

Normal project cleanup (deleting `dist/`, `node_modules/`) passes through.

<Callout type="warning">
  The hook does not replace Antigravity permissions, workspace trust, sandboxing, or human approval. It is a last-resort tripwire, not a security boundary.
</Callout>

## MCP synchronization

`.agents/mcp_config.json` is the workspace source for MCP servers. The sync helper applies it explicitly — it refuses placeholder credentials, preserves conflicting entries by default, and backs up the target before writing:

<Terminal>
  <TerminalLine type="user">node .agents/hooks/sync-mcp.mjs</TerminalLine>
</Terminal>

## Planner + Flash Worker Pattern

Pair a high-reasoning planner in the main session with the scoped `worker` subagent (`model: flash`) to keep quota costs low and prevent whole-file read spam:

1. **Main session (Planner)** — Select your planner model in the Antigravity model picker (or `/model`). Locate target files, line ranges, and symbols before delegating.
2. **Scoped worker (`.agents/agents/worker.md`)** — Discovered natively by Antigravity `/agents`. Runs on `model: flash` and only reads bounded line ranges inside explicitly named files.
3. **Delegation rules (`AGENTS.md`)** — Pass exact file paths, line ranges or symbol names, a narrow objective, and the verification command; keep tiny single-line edits in the main session.

Verify discovery in the CLI or Agents panel with `/agents` (`worker` appears under Available Agents) and inspect its tool log in the Subagent Detail View.
