### `agx-kit update`

អាប់ដេតថត `.agents` ដែលមានស្រាប់ជាមួយនិយមន័យ toolkit ចុងក្រោយបំផុត។

<Terminal>
  <TerminalLine type="user">bunx agx-kit update</TerminalLine>
</Terminal>

<Callout type="warning" title="សេចក្តីជូនដំណឹងអំពីការកែប្រែដោយផ្ទាល់">
  ការកែប្រែឯកសារគ្រប់គ្រងដោយ kit ដោយផ្ទាល់អាចបណ្តាលឱ្យមានជម្លោះ update។ សូមប្រើប្រាស់ local overrides ឬការកំណត់ agent ផ្ទាល់ខ្លួនតាមដែលអាចធ្វើទៅបាន។
</Callout>

## ជម្រើស និងទង់កំណត់ (Options & Flags)

| ជម្រើស | ការពិពណ៌នា |
|---|---|
| `-f, --force` | បង្ខំឱ្យសរសេរជាន់លើថត `.agents` ដែលមានស្រាប់ក្នុងកំឡុងពេល `init` ឬ `update`។ |
| `-p, --path <dir>` | ថតគោលដៅសម្រាប់ការដំឡើង (លំនាំដើមគឺថតការងារបច្ចុប្បន្ន)។ |
| `-b, --branch <name>` | មែកធាង Git ឬ tag ដែលត្រូវដំឡើង។ |
| `-q, --quiet` | បិទការបង្ហាញលទ្ធផលដែលមិនមែនជាកំហុសកំឡុងពេលដំណើរការ។ |
| `--dry-run` | មើលឯកសារសាកល្បងដែលនឹងត្រូវបង្កើត, update, ឬមានជម្លោះ ដោយមិនសរសេរទៅលើថាស។ |
| `--strategy <merge\|replace>` | យុទ្ធសាស្ត្រសម្រាប់ការ update: `merge` (លំនាំដើម, រក្សាឯកសារផ្ទាល់ខ្លួន) ឬ `replace` (សរសេរជាន់ថ្មីទាំងអស់)។ |
| `--no-backup` | រំលងការបង្កើត backup ស្វ័យប្រវត្តមុនពេលកែប្រែឯកសារ។ |
| `--conflict-report <file>` | ផ្លូវឯកសារដែលត្រូវសរសេររបាយការណ៍ជម្លោះជា JSON។ |

## ឧទាហរណ៍ទូទៅ (Common Examples)

### បង្ខំឱ្យដំឡើងឡើងវិញ

```bash
bunx agx-kit init --force
```

### ការសាកល្បង Update ជាមុន (Dry Run)

```bash
bunx agx-kit update --dry-run
```

### ការ Update ដោយប្រើ Replace Strategy

```bash
bunx agx-kit update --strategy replace
```

### ការស្តារ Backup ជាក់លាក់ណាមួយ

```bash
bunx agx-kit rollback --backup 2026-07-26T16-03-21
```
