## តើអ្វីជា Skills? (What are Skills?)

Skills គឺជាកញ្ចប់ចំណេះដឹងបែបម៉ូឌុលដែលមាន គោលការណ៍ (principles), លំនាំដោះស្រាយ (patterns), និងក្របខ័ណ្ឌធ្វើការសម្រេចចិត្តសម្រាប់វិស័យជាក់លាក់។ ពួកវាត្រូវបានផ្ទុកឡើងដោយស្វ័យប្រវត្តនៅពេល agent ត្រូវការ។

ផ្ទុយពី template រឹងស្តូក ជំនាញទាំងនេះបង្រៀនអំពី *គោលការណ៍គ្រឹះ* — ជួយឱ្យ agent ធ្វើការសម្រេចចិត្តសមស្របតាមបរិបទជាជាងការចម្លងតាមគំរូចាស់ៗ។

<Callout type="info" title="ការផ្ទុកឡើងដោយស្វ័យប្រវត្តិ">
  Skills ត្រូវបានផ្ទុកឡើងតាមតម្រូវការជាក់ស្តែងនៃបរិបទកិច្ចការ។ អ្នកមិនចាំបាច់កំណត់រចនាសម្ព័ន្ធអ្វីដោយដៃឡើយ។
</Callout>
