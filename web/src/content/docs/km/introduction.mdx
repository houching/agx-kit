**AGX Kit** គឺជាឧបករណ៍វិស្វកម្ម AI Agent សម្រាប់បរិស្ថានផលិតកម្ម ដែលមាន rules, modular skills, specialist agents, និង workflows ត្រូវបានរចនាឡើងយ៉ាងពិសេសសម្រាប់ Google Antigravity និងលំហូរការងារសរសេរកូដឆ្លាតវៃទំនើប។

មិនថាអ្នកជាវិស្វករឯករាជ្យ ឬជាអ្នកដឹកនាំក្រុមនោះទេ AGX Kit កំណត់របាំងឥរិយាបថច្បាស់លាស់ ទប់ស្កាត់ការរីកសាយវិសាលភាពការងារដោយមិនចាំបាច់ និងធានាថាការអភិវឌ្ឍកម្មវិធីមានភាពជឿជាក់ និងអាចធ្វើឡើងវិញបាន។

## របៀបប្រើប្រាស់ឯកសារ (How to Use the Docs)

ឯកសារត្រូវបានរៀបចំជា 4 ផ្នែកចម្បង៖

1. **ការចាប់ផ្តើម (Getting Started)**:
   - [សេចក្តីផ្តើម (Introduction)](/km/introduction/): ទិដ្ឋភាពទូទៅ និងស្ថាបត្យកម្មប្រព័ន្ធ។
   - [ការដំឡើង (Installation)](/km/installation/): របៀបដំឡើង AGX Kit ជាសកល ឬតាមគម្រោងតាមរយៈ Bun ឬ npm។
2. **គំនិតស្នូល (Core Concepts)**:
   - [Agents](/km/agents/): 20 តួអង្គជំនាញ និងលក្ខខណ្ឌប្រើប្រាស់។
   - [Skills](/km/skills/): 45 ជំនាញតាមវិស័យរៀបចំតាមប្រភេទ។
   - [Workflows](/km/workflows/): ពាក្យបញ្ជា slash commands សម្រាប់ការអភិវឌ្ឍជាលំដាប់លំដោយ។
   - [ការអាប់ដេត និង Rollback (Updates & Rollback)](/km/updates/): ការគ្រប់គ្រង SHA-256 manifest locking, ការ merge ដោយសុវត្ថិភាព និងការ rollback ភ្លាមៗ។
   - [Antigravity Runtime](/km/antigravity/): Native hooks, ការធ្វើសមកាលកម្ម MCP និងសុខភាពប្រព័ន្ធ។
3. **ការណែនាំអនុវត្ត (Guide)**:
   - មេរៀនអនុវត្តជាក់ស្តែង 10 រួមមាន ការពិគ្រោះយោបល់, ការរៀបចំផែនការ, ការកសាងកម្មវិធី, ការកែកំហុស, ការបង្កើតតេស្ត និងការដាក់ពង្រាយផលិតកម្ម។
4. **ឯកសារយោង (Reference)**:
   - [ពាក្យបញ្ជា និងជម្រើស (Commands & Options)](/km/cli/): វាក្យសម្ព័ន្ធ CLI ជម្រើស និងទង់កំណត់ពេញលេញ។
   - [កំណត់ហេតុបម្រែបម្រួល (Changelog)](/km/changelog/): ប្រវត្តិនៃកំណែនីមួយៗ និងកំណត់ចំណាំការ upgrade។
