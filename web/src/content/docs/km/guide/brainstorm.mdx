## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/brainstorm` ដំណើរការ **របៀបបំផុសគំនិតតាមរចនាសម្ព័ន្ធ**។
ជំនួសឱ្យការចាប់ផ្តើមសរសេរកូដភ្លាមៗ ភ្នាក់ងារនឹងស្វែងយល់យ៉ាងហោចណាស់ ៣ វិធីសាស្រ្តផ្សេងគ្នា
វិភាគចំណុចល្អ និងចំណុចខ្សោយ ហើយជួយអ្នកធ្វើការសម្រេចចិត្តប្រកបដោយទំនុកចិត្ត។

## ដំណើរការការងារ (The Process)

<StepList>
  <Step number={1} title="រៀបរាប់ពីបញ្ហាប្រឈមរបស់អ្នក">
    ប្រាប់ភ្នាក់ងារពីអ្វីដែលអ្នកចង់ស្វែងយល់។ បញ្ជាក់ឱ្យច្បាស់ពីលក្ខខណ្ឌកំណត់បច្ចេកទេស។

    ```bash
    /brainstorm authentication system for my SaaS app
    ```
  </Step>
  <Step number={2} title="ពិនិត្យមើលជម្រើស">
    ភ្នាក់ងារបង្ហាញ ៣+ វិធីសាស្រ្ត ជាមួយនឹងចំណុចខ្លាំង ចំណុចខ្សោយ និងកម្រិតកិច្ចខិតខំប្រឹងប្រែង។
  </Step>
  <Step number={3} title="ធ្វើការសម្រេចចិត្ត">
    ជ្រើសរើសជម្រើសមួយ បន្ទាប់មកបន្តទៅការអនុវត្តតាមរយៈ `/plan`, `/create` ឬ `/enhance`។
  </Step>
</StepList>
