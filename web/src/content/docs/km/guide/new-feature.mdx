## ទិដ្ឋភាពទូទៅ (Overview)

លំហូរការងារ `/enhance` គឺជាឧបករណ៍ប្រចាំថ្ងៃរបស់អ្នកសម្រាប់ការអភិវឌ្ឍន៍ជាបន្តបន្ទាប់។
ខុសពី `/create` ដែលបង្កើតគម្រោងពីដំបូង `/enhance` ផ្តោតលើការបន្ថែមមុខងារជាក់លាក់ដោយមិនធ្វើឱ្យប៉ះពាល់ ឬបែកបាក់កូដចាស់ដែលមានស្រាប់ឡើយ។

<Callout type="info">
  **ស្ថានភាពជាក់ស្តែង៖** បន្ថែមមុខងារ "Dashboard Analytics" ទៅក្នុងកម្មវិធី SaaS ដែលមានស្រាប់។
</Callout>

---

## ដំណើរការការងារ (The Process)

<StepList>
  <Step number={1} title="ការរៀបចំផែនការមុខងារ">
    រៀបរាប់ពីតម្រូវការមុខងារឱ្យបានច្បាស់លាស់។

    ```bash
    /enhance Add an analytics dashboard for user activity
    Requirements:
    - Track daily active users and page views
    - Visual charts using Recharts
    - API endpoint to aggregate data
    ```
  </Step>
  <Step number={2} title="ការអនុវត្តសមាសភាគ">
    ភ្នាក់ងារជំនាញអនុវត្តការងារគ្រប់ស្រទាប់៖

    <FeatureGrid cols={4}>
      <Feature title="Database" description="Schema & migrations" />
      <Feature title="Backend" description="Aggregator routes" />
      <Feature title="Frontend" description="Telemetry charts" />
      <Feature title="Testing" description="Regression tests" />
    </FeatureGrid>
  </Step>
  <Step number={3} title="ផ្ទៀងផ្ទាត់ការរួមបញ្ចូល">
    ដំណើរការការត្រួតពិនិត្យចុងក្រោយដើម្បីបញ្ជាក់ពីទំហំ bundle, accessibility និងតេស្ត។
  </Step>
</StepList>
