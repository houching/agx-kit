## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/preview` គ្រប់គ្រង dev server ក្នុងស្រុករបស់អ្នក។
ចាប់ផ្តើម បញ្ឈប់ ចាប់ផ្តើមឡើងវិញ ឬពិនិត្យស្ថានភាពតាមរយៈពាក្យបញ្ជាសាមញ្ញ។

  <Feature title="start" description="ដំណើរការ server" />
  <Feature title="stop" description="បញ្ឈប់ server" />
  <Feature title="restart" description="ផ្ទុកឡើងវិញបរិស្ថាន" />
  <Feature title="check" description="ស្ថានភាពសុខភាព" />
</FeatureGrid>

## ដំណើរការការងារ (The Process)

  </Step>

  <Step number={3} title="បញ្ឈប់ Server (Stop Server)">
