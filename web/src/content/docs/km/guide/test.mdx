## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/test` ចាត់ចែងលើ **ការបង្កើត និងដំណើរការតេស្ត**។
វិភាគកូដ បង្កើតឈុតតេស្ត ដំណើរការតេស្ត ឬពិនិត្យមើលការគ្របដណ្តប់ (coverage)។

## គន្លឹះមានប្រយោជន៍ (Pro Tips)

  <Tip title="តេស្តឥរិយាបថ">
    ផ្តោតលើអ្វីដែល function ធ្វើ មិនមែនការអនុវត្តខាងក្នុង។

    តែងតែតេស្តកំហុស, input ទទេ, និងតម្លៃព្រំដែន។
  </Tip>
</ProTips>
