## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/deploy` ដើរតួជា **Audit & Release Conductor**។
វាបង្ខំឱ្យកូដរបស់អ្នកឆ្លងកាត់ការត្រួតពិនិត្យសុខភាពយ៉ាងម៉ត់ចត់មុនពេលដំណើរការ deploy។

<Callout type="info" title="វាបញ្ឈប់អ្នកពីការ deploy ប្រសិនបើ៖">
  - រកឃើញភាពងាយរងគ្រោះផ្នែកសុវត្ថិភាព (Security vulnerabilities)
  - មានកំហុស Linting (Linting errors)
  - ប្រភេទ TypeScript មិនត្រឹមត្រូវ (Invalid types)
  - តេស្តសំខាន់ៗបរាជ័យ (Failed critical tests)
</Callout>

---

## ដំណើរការការងារ (The Process)

<StepList>
  <Step number={1} title="ដំណើរការពាក្យបញ្ជា (Execute Command)">
    នៅពេលកូដរបស់អ្នករួចរាល់ ចាប់ផ្តើមដំណើរការ deployment pipeline៖

    ```bash
    /deploy
    ```
  </Step>
  <Step number={2} title="ការត្រួតពិនិត្យមុនបញ្ចេញ (Pre-Flight Checklist)">
    Agent នឹងធ្វើសវនកម្មសុខភាពគម្រោងរបស់អ្នកដោយស្វ័យប្រវត្តិ៖

    <div class="grid grid-cols-1 md:grid-cols-2 gap-4 mt-4">
      <div class="bg-[var(--v-surface)] border border-[var(--v-line)] rounded-lg p-3">
        <h4 class="text-sm font-semibold mb-1 text-[var(--v-text-1)]">🛡️ សុវត្ថិភាព (Security)</h4>
        <p class="text-xs text-[var(--v-text-2)] m-0">ស្កេនរកភាពងាយរងគ្រោះ និងការធ្លាយ secrets</p>
      </div>
      <div class="bg-[var(--v-surface)] border border-[var(--v-line)] rounded-lg p-3">
        <h4 class="text-sm font-semibold mb-1 text-[var(--v-text-1)]">📋 គុណភាពកូដ (Quality)</h4>
        <p class="text-xs text-[var(--v-text-2)] m-0">ត្រួតពិនិត្យភាពស្អាតនៃ Linting & Type Safety</p>
      </div>
    </div>
  </Step>
  <Step number={3} title="ការបញ្ចេញជាផ្លូវការ (Release)">
    ប្រសិនបើការត្រួតពិនិត្យទាំងអស់បានឆ្លងកាត់ វាដំណើរការ build និង deploy ទៅកាន់ platform គោលដៅ (Vercel, Cloudflare, Docker)។
  </Step>
</StepList>

## គន្លឹះមានប្រយោជន៍ (Pro Tips)

<ProTips>
  <Tip title="សាកល្បងពិនិត្យជាមុន">
    ដំណើរការ `/deploy check` ដើម្បីធ្វើការផ្ទៀងផ្ទាត់សាកល្បងដោយមិនទាន់ deploy ពិតប្រាកដ។
  </Tip>
  <Tip title="សុវត្ថិភាព Rollback">
    ប្រើប្រាស់ `/deploy rollback` ដើម្បីបង្វិលត្រឡប់ទៅកំណែមានស្ថេរភាពចុងក្រោយភ្លាមៗ។
  </Tip>
</ProTips>
