## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/plan` ដំណើរការ **របៀបរៀបចំផែនការសុទ្ធសាធ (planning-only mode)**។
វាប្រើប្រាស់ភ្នាក់ងារ `project-planner` ដើម្បីបង្កើតឯកសារផែនការលម្អិតដោយមិនសរសេរកូដឡើយ។

<Callout type="info" title="វិធានការតឹងរ៉ឹង៖">
  **មិនមានកូដណាមួយត្រូវបានសរសេរកំឡុងពេលរៀបចំផែនការឡើយ។** មានតែឯកសារផែនការ `{task-slug}.md` (នៅ root នៃគម្រោង) ប៉ុណ្ណោះដែលត្រូវបានបង្កើត។
</Callout>

---

## ដំណើរការការងារ (The Process)

<StepList>
  <Step number={1} title="រៀបរាប់ពីគម្រោងរបស់អ្នក">
    ប្រាប់អ្នករៀបចំផែនការពីអ្វីដែលអ្នកចង់បង្កើត។

    ```bash
    /plan e-commerce site with cart and checkout
    ```
  </Step>
  <Step number={2} title="សំណួរបែប Socratic">
    អ្នករៀបចំផែនការសួរសំណួរដេញដោលអំពីតម្រូវការមុនពេលបង្កើតផែនការ។
  </Step>
  <Step number={3} title="បង្កើតផែនការរួចរាល់">
    បង្កើតឯកសារ `{task-slug}.md` នៅ root នៃគម្រោងជាមួយកិច្ចការ និងការបែងចែកភ្នាក់ងារ។
  </Step>
</StepList>
