## ទិដ្ឋភាពទូទៅ (Overview)

ពាក្យបញ្ជា `/create` គឺជា **application creation wizard** របស់អ្នក។
វាណែនាំអ្នកឆ្លងកាត់ការសន្ទនាអន្តរកម្ម ស្វែងយល់ពីតម្រូវការរបស់អ្នក
រៀបចំផែនការស្ថាបត្យកម្ម និងសម្របសម្រួលភ្នាក់ងារឯកទេសដើម្បីបង្កើតកម្មវិធីរបស់អ្នក។

<Callout type="info">
  **ពីគំនិតទៅជាកម្មវិធីដែលដំណើរការជាក់ស្តែង៖** គ្រាន់តែរៀបរាប់ពីអ្វីដែលអ្នកចង់បាន នោះ wizard នឹងចាត់ចែងរៀបចំ tech stack, រចនាសម្ព័ន្ធឯកសារ, database schema និងការសរសេរកូដដោយភ្នាក់ងារជំនាញ។
</Callout>

## ដំណើរការការងារ (The Process)

<StepList>
  <Step number={1} title="រៀបរាប់ពីកម្មវិធីរបស់អ្នក">
    ប្រាប់ wizard ពីអ្វីដែលអ្នកចង់បង្កើត។ វានឹងសួរសំណួរបញ្ជាក់បន្ថែមប្រសិនបើចាំបាច់។

    ```bash
    /create e-commerce site with product listing and cart
    ```
  </Step>
  <Step number={2} title="ពិនិត្យមើលផែនការ">
    ភ្នាក់ងារ `project-planner` បង្កើតផែនការលម្អិត។ យល់ព្រមដើម្បីបន្ត។
  </Step>
  <Step number={3} title="ភ្នាក់ងារចាប់ផ្តើមសរសេរកូដ">
    ភ្នាក់ងារឯកទេសធ្វើការស្របគ្នា៖ database-architect, backend, frontend។
  </Step>
</StepList>
