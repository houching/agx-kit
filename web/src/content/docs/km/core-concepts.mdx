## គោលការណ៍ស្ថាបត្យកម្ម (Architectural Principles)

1. **ដោះស្រាយការពឹងផ្អែកពីម៉ូឌុលចុងក្រោយ (Leaf-First)**៖ ការផ្លាស់ប្តូរទាំងអស់ត្រូវបានផ្ទៀងផ្ទាត់ចេញពី leaf module ជាមុនសិន មុនពេលប៉ះពាល់ដល់ស្រទាប់សម្របសម្រួល។
2. **Oracle Parity និងគ្មានការកែប្រែតេស្ត**៖ ឈុតតេស្តដែលមានស្រាប់គឺជាការពិតដាច់ខាត។ កែកូដឱ្យត្រូវ មិនត្រូវបន្ទាបលក្ខខណ្ឌតេស្តឡើយ។
3. **រចនាប័ទ្មបច្ចេកទេស Vantage**៖ បង្កើតឡើងដោយប្រើផ្ទាំង Vantage (`#0d0f12` slate canvas, ខ្សែបន្ទាត់ 1px hairline, លេខ monospace)។
4. **ឯករាជ្យភាពមូលដ្ឋាន (Local Sovereignty)**៖ រាល់ការណែនាំ ច្បាប់ ការចងចាំ និងស្គ្រីបរបស់ភ្នាក់ងារគឺស្ថិតនៅក្នុងថត `.agents/` ផ្ទាល់នៃគម្រោងរបស់អ្នក។
