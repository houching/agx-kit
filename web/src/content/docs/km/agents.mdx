## តើអ្វីជា Agents? (What are Agents?)

Agents គឺជាតួអង្គ AI ឯកទេសដែលត្រូវបានរៀបចំឡើងជាមួយជំនាញតាមផ្នែក ឧបករណ៍ចាំបាច់ និងលំនាំឥរិយាបថស្តង់ដារ។ Agent នីមួយៗត្រូវបានរចនាឡើងដើម្បីពូកែលើផ្នែកណាមួយជាក់លាក់នៃការអភិវឌ្ឍកម្មវិធី។

នៅពេលអ្នកដាក់សំណើ ប្រព័ន្ធ **Intelligent Routing** របស់ AGX Kit នឹងស្វែងរក និងដំណើរការ agent ដែលត្រូវគ្នានឹងតម្រូវការដោយស្វ័យប្រវត្តិ។ អ្នកក៏អាចហៅឈ្មោះ agent ផ្ទាល់ដើម្បីបង្ខំឱ្យប្រើទស្សនៈជាក់លាក់ណាមួយបានផងដែរ។

---

## របៀបប្រើប្រាស់ Agents (How to Use Agents)

**មិនចាំបាច់ហៅឈ្មោះ agent ដោយផ្ទាល់នោះទេ!** ប្រព័ន្ធនឹងរកឃើញ និងជ្រើសរើសអ្នកជំនាញដែលស័ក្តិសមដោយស្វ័យប្រវត្តផ្អែកលើសំណើរបស់អ្នក៖

<Terminal>
  <TerminalLine type="user">Add JWT authentication</TerminalLine>
  <TerminalBlock>
    <div class="text-xs text-teal-400">🤖 កំពុងដំណើរការចំណេះដឹងរបស់ @security-auditor + @backend-specialist...</div>
  </TerminalBlock>

  <TerminalLine type="user">Fix the dark mode button</TerminalLine>
  <TerminalBlock>

  </TerminalBlock>

ទោះយ៉ាងណាក៏ដោយ អ្នក **នៅតែអាចកំណត់ដោយផ្ទាល់** បានប្រសិនបើចង់បាន៖

```text
ប្រើប្រាស់ agent security-auditor ដើម្បីពិនិត្យមើលផ្ទៀងផ្ទាត់ Authentication...
```

<Callout type="tip" title="ការធ្វើការងារជាក្រុម & Orchestration">
  Agent អាចសហការគ្នាបាន! ប្រើប្រាស់ agent <code>orchestrator</code> ដើម្បីសម្របសម្រួលអ្នកជំនាញជាច្រើនក្នុងកិច្ចការស្មុគស្មាញ។
</Callout>

## រចនាសម្ព័ន្ធរបស់ Agent (Agent Structure)

Agent នីមួយៗត្រូវបានកំណត់តាមរយៈឯកសារ markdown ជាមួយ YAML frontmatter៖

```markdown
---
name: frontend-specialist
description: Frontend architect expert
tools: Read, Edit, Write, Bash
skills: nextjs-react-expert, tailwind-patterns, frontend-design
---

# Frontend Specialist

You are a senior frontend architect...
```

ប្រអប់ `skills` កំណត់ថាតើ agent អាចចូលប្រើប្រាស់ម៉ូឌុលចំណេះដឹងណាខ្លះ។
