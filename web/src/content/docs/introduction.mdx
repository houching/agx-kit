**AGX Kit** is a production AI agent engineering toolkit with rules, modular skills, specialist agents, and workflows designed specifically for Google Antigravity and modern agentic coding workflows.

Whether you are working as an individual engineer or leading a team, AGX Kit establishes clear behavioral guardrails, prevents scope creep, and ensures reliable, reproducible software development.

## How to Use the Docs

The documentation is organized into 4 logical sections:

1. **Getting Started**:
   - [Introduction](/introduction/): High-level overview and ecosystem architecture.
   - [Installation](/installation/): How to install AGX Kit globally or per-project via Bun or npm.
2. **Core Concepts**:
   - [Agents](/agents/): 20 specialized personas and their triggers.
   - [Skills](/skills/): 45 domain skills organized by category.
   - [Workflows](/workflows/): Interactive slash commands for structured development.
   - [Managed Updates & Rollback](/updates/): SHA-256 manifest locking, non-destructive merges, and instant rollback.
   - [Antigravity Runtime](/antigravity/): Runtime hooks, MCP registry integration, and health diagnostics.
3. **Guide**:
   - 10 hands-on execution walkthroughs spanning brainstorming, task planning, app scaffolding, debugging, testing, and production deployment.
4. **Reference**:
   - [Commands & Options](/cli/): Complete CLI command line syntax, flags, and options.
   - [Changelog](/changelog/): Detailed version history and upgrade notes.
